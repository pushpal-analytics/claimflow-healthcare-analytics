## Project Overview
Healthcare providers lose millions of dollars every year due to insurance claim denials, billing errors, and delayed payments[span_0](start_span)[span_0](end_span). 

**ClaimFlow** is an end-to-end data analytics project built to tackle this challenge[span_1](start_span)[span_1](end_span). It provides billing teams and executives with clear visibility into claim statuses, high-risk insurance payers, and recoverable revenue[span_2](start_span)[span_2](end_span).

## Technical Architecture
The data pipeline moves from data generation to storage, cleaning, data modeling, and final interactive visualization[span_4](start_span)[span_4](end_span).

<p align="center">
  <img src="./Docs/03_project_workflow.png" alt="Technical Data Pipeline" width="100%"/>
</p>

* **Data Generation:** Python script simulating realistic healthcare claim scenarios[span_5](start_span)[span_5](end_span).
* **Database & Storage:** SQL Server for database creation, structure, and query analysis[span_6](start_span)[span_6](end_span).
* **ETL & Data Cleaning:** Power Query for data transformation and deduplication[span_7](start_span)[span_7](end_span).
* **Data Modeling:** Star Schema with 1 Fact table (`fact_claims`) and 3 Dimension tables (`dim_hospitals`, `dim_payers`, `dim_date`)[span_8](start_span)[span_8](end_span).
* **Visualization:** Power BI desktop using DAX measures, dynamic filtering, and custom layouts[span_9](start_span)[span_9](end_span).

## Key Business Insights
1. **High Commercial Denials:** Commercial payers average a 15–18% denial rate, mostly caused by missing documentation during billing submission[span_10](start_span)[span_10](end_span).
2. **Pending Cash Flow:** Over $450K in revenue remains stuck in pending status, with nearly 20% delayed for over 90 days[span_11](start_span)[span_11](end_span).
3. **Appeals Opportunity:** Filing systematic claim appeals successfully recovers up to 50% of denied revenue[span_12](start_span)[span_12](end_span).
